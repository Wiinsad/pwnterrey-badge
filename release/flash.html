Firmware v2.1 — Pwnterrey 2026

Flashea el firmware del badge Pwnterrey directamente desde tu navegador. No necesitas instalar nada.

  1. Conecta tu badge por USB-C
  2. Haz clic en Instalar
  3. Selecciona el puerto serial
  4. Espera a que termine (~60 segundos)
Tu navegador no soporta Web Serial.
Usa Google Chrome o Microsoft Edge en escritorio.

¿Problemas? Consulta el README para flasheo manual por terminal.
